# FL2／FL3：第一次安装的完整操作说明

[返回首页](../../README.zh-CN.md) · [English](../en/fl23.md)

这个入口为符合条件的 **Sony A7C II／ILCE-7CM2 固件 2.01** 增加 FL2、FL3 创意外观。Windows **优先使用命令行**，也可双击 **`FL23.cmd`** 使用原图形界面；两者调用同一个后端。它不负责导入你自己的 DCP／LUT；那是[独立的自定义外观流程](custom-lut.md)。

## 优先使用命令行

准备、安装、核对和还原分别对应 `prepare`、`install`、`verify`、`restore`。完整参数与顺序见[FL23 AI 复现说明](fl23-ai.md)和[命令参考](manual.md)，每一步成功后才运行下一步，不要整段连跑。先查看帮助，不连接相机：

```text
.\FL23.cmd --help
```

下文保留桌面按钮说明：备份与检查=`prepare`，安装预览版=`install`，重开后核对=`verify`，回復本次安裝=`restore`。命令行和桌面版都必须满足相同版本、备份、电量和读回条件。

它会修改相机程序和相关外观参数，仍是单台机身通过基础测试的实验工具，并非 Sony 官方签名更新。以下步骤能解释正常流程，不保证任何失败后的恢复。FL23 设备安装使用 Windows；[Mac 安装准备](manual.md)针对独立 LUT 工具，Mac USB 尚未验证。

## 1. 先确认机身和电脑是否适用

- 相机是 **A7C II／ILCE-7CM2**，不是 A7C、A7CR 或 A7 IV。
- 相机版本页面显示 **2.01**；请如实填写版本。工具不自动读取版本，也不验证固件来源。
- 允许已修改的 2.01，不再以原厂/仓库固件哈希拒绝；改写位置有实际冲突时仍停止。
- 电脑为 Windows，装有含 `py` 启动器及 Tkinter 的 64 位 Python 3.10+；首次启动需联网安装依赖。
- 有可传数据的 USB 线、充足电量，并能保持连接到读回检查完成。安装和还原要求实际电量至少 50%。

已有单台机身的 FL2／FL3／ST 拍照和回放成功记录；其他机身、长期使用及所有拍摄模式并未完整验证。具体证据见[验证记录](technical/validation.md)。

### 开发版：按版本安装，不检查固件来源

此修复已包含在 `feature/backup2-rollback`，不在旧 v2.1 下载中。离线验证通过，尚未实机验证；USB 连接流程未改。

不再用原厂或本仓库的完整固件哈希作为安装门槛。机型仍由 USB 查询；版本按相机版本页面填写，**不是工具自动读取**。桌面版填写 `2.01`；命令行 `prepare` 增加 `--firmware-version 2.01`。安装前弹窗提醒，命令行显示同样提醒：其他项目修改过的固件可能冲突、导致无法正常启动。

不需要先卸载六款 LUT。保留现有 LUT 转换入口、CP 色表、名称和配方；已有 FL23 时核对目标参数/绑定，只备份与验证、不重复安装。需要改写的位置若出现不同指令，会明确报告地址冲突，不盲目覆盖；这不是固件来源白名单。

备份和写后完整字节读回仍保留，不要求匹配原厂。新版 `restore` 使用初始完整存档，后续 LUT 不会挡住回退；旧 backup2 需先补齐名称资源，见下方「回到最初 backup2」。回退目标是备份时的状态，当时已存在的 FL23 也会保留。

## 2. 下载、解压并打开界面

下载当前[完整工具包 a7c2-tools-2.1.zip](https://github.com/QAQLeonard/a7c2-fl23-research/releases/download/v2.1/a7c2-tools-2.1.zip)并解压，[Release 页面](https://github.com/QAQLeonard/a7c2-fl23-research/releases/tag/v2.1)保留附件和校验值。不要在压缩包预览窗口里直接双击，也不要只拿一个 `.cmd` 文件出来。

打开解压目录中的 `FL23.cmd`。首次启动会准备本地 Python 环境，完成后出现 FL2／FL3 界面。平常双击即可；只有想手动调用或排查启动时，才需要[手动命令](manual.md)。不需要升级 PowerShell 或修改它的执行策略。

看不到界面时，先检查是否装好 Python、能否联网、解压是否完整。此时先解决电脑启动问题，不要开始相机安装。

## 3. 连接相机并准备 USB 驱动

1. 在相机选择 **USB 大量存储／Mass Storage**，再用数据线连接电脑。电脑遥控／PC Remote 是另一种模式。
2. 使用 [Zadig](https://zadig.akeo.ie/) 为相机的指定 USB 身份安装 **libusbK**。必要时在其菜单启用 **Options → List All Devices**，按 USB ID 确认目标。
3. 相机普通身份是 `054C:0E8A`；工具进入服务连接后可能出现另一个身份 `054C:0336`。二者需分别匹配驱动，服务身份在首次认证后才出现。

USB ID 可以理解为设备身份证号。只选择与上述 ID 相符的相机，不能因为名称相似就修改鼠标、键盘、读卡器或其他设备。驱动装好本身不等于已经刷写固件。

首次备份时若因为服务身份尚无驱动而停止，先保留失败目录，记录日志。确认未发生未知写入、仅缺少该身份驱动后，准备对应驱动，再按已确认的状态重新准备；不要连续点击安装。

### 首次替换驱动后断开／提示「请检查所连接的设备」

有用户反馈：普通身份替换为 libusbK 后，首次连接倒计时结束，相机显示「请检查所连接的设备」；分别处理普通／服务身份驱动后完成安装，之后连接正常。这是用户报告的处理经验，尚未独立复现同一故障。代码确实会在首次认证时切换 USB 身份，但仅凭相机这条提示不能确定是驱动问题。

| 阶段 | Zadig／设备管理器常见名称 | 必须核对的 USB ID |
|---|---|---|
| 普通大量存储连接 | ILCE-7CM2 | `054C:0E8A` |
| 工具认证后的服务连接 | Sony USB Device | `054C:0336` |

设备名称变化由相机进入服务模式引起，不是 Zadig 自己切换相机；`Replace Driver`／`Install Driver` 按钮文字取决于当前设备的驱动状态。**两个 USB 身份要分别安装 libusbK。** 替换后资源管理器可能不再显示普通相机磁盘，这不等于工具无法连接。

仅在工具读写已结束、确认还没开始固件写入时，可按下面排查：

1. 若 `ILCE-7CM2` 的驱动绑定异常，在设备管理器按硬件 ID 确认是 `054C:0E8A`，卸载该设备；需要重建这项绑定时勾选「删除此设备的驱动程序软件」（若有）。这不是每次安装必做的步骤，不卸载其他设备。
2. 重新插拔 USB，确认相机仍为大量存储模式。在 Zadig 启用 **Options → List All Devices**，选择 `ILCE-7CM2 / 054C:0E8A`，目标驱动选 **libusbK**，点击 **Replace Driver** 或 **Install Driver**。
3. 先只运行 **「1 备份与检查」／`prepare`**。工具首次认证后，相机可能重新枚举为 `Sony USB Device / 054C:0336`；若因此缺驱动而停止，等命令结束，再在 Zadig 选择这个新身份并安装 **libusbK**。不要把普通身份已经装好理解为服务身份也已装好。
4. 保留刚才的失败目录和日志；确认只是准备阶段缺驱动后，选两个新的空白工作／备份目录，再运行一次「备份与检查」。成功后才继续正式安装。已开始写入、出现 `needs_review` 或结果未知时，不套用这套重试步骤，先检查原任务状态。

更换驱动不等于刷写成功；若两种身份驱动都已匹配仍报错，保留最后日志和当前 USB ID，继续区分设备忙碌、认证失败与实际传输错误。

## 4. 填好两个目录和电量

界面里的字段分别是：

| 界面字段 | 用途 | 示例 |
|---|---|---|
| 機身工作目錄 | 保存这次操作的原档、候选、状态和日志 | `D:/CameraWork-A7C2-01` |
| 第二份備份 | 单独保留这台机身的原始数据副本 | `E:/CameraBackup-A7C2-01` |
| 相機目前電量 | 实际剩余百分比，安装和还原前填写 | 例如 `82`，不要照抄示例 |

首次准备时使用**两个不同的新空白目录**，最好位于不同磁盘。工作目录用于继续这次操作，第二份备份用于保留独立副本；不要把二者选成同一个文件夹，也不要为“从头来”而清空旧目录。

这些备份属于当前机身，可能包含私人设置／校准。妥善保存，不上传 GitHub、不发给其他人当通用固件，也不拿别人的备份来替代。

## 5. 点击「1 備份與檢查」

这一步先读取当前机身的程序和设置，检查本次实际改写位置是否冲突，保存两份备份，生成修改候选，并运行实机只校验。它会使用临时诊断，但还不会把候选程序写入相机或保存新的拍摄设置。

等待下方日志完成。**完成标准：**看到“備份、候選與實機只校驗完成。尚未改寫韌體或保存拍攝設定。”且没有错误。界面单纯显示“处理完成”或磁盘里出现了文件，不足以代替这条实际结果。

工作目录会有 `state.json`、`original` 和 `candidate` 等内容。你不需要手动修改它们；`state.json` 记录工具走到了哪一步，原档在 `original`，准备写入的文件在 `candidate`。准备成功状态为 `prepared`，仅供排查时查看，不要手改状态来放行。

如果提示改写位置冲突、备份不符或目标区域已使用，就停在这里查原因。不要虚报版本、覆盖冲突代码或拿另一台机身的备份继续。

## 6. 点击「2 安裝預覽版」

只有上一步成功后才继续，沿用同一个工作目录，填写真实电量并保持 USB 供电／数据连接。**这个按钮才会写入相机。**

工具写入受保护的程序窗口和新增外观参数，再从相机读回核对，并处理旧启动镜像。读回就是把写入后的数据再读取比较，并不等同于已经测试拍摄。

**完成标准：**日志明确显示“安裝及讀回完成”，没有错误；工作状态为 `installed_pending_cold_start`，表示写入完成、还要重新加载。处理期间不要关机、拔线、关闭窗口或再次启动另一个相机操作程序。

## 7. 写入结束后，让相机重新加载

1. 确认工具所有读写都已结束。
2. 拔下 USB 和其他供电，正常关机。
3. 等屏幕和存取灯熄灭，取出电池至少 **一分钟**，然后装回开机。工具旧提示可能写十秒，本说明统一使用更长的完整断电步骤。
4. 在相机进入创意外观清单，检查 FL2／FL3 是否出现。需要按界面提示重设新增外观时，先记录要保留的调整，再使用相机对该外观的重设操作；不要为此初始化整台相机。

这一步的目的，是让相机从更新后的存储内容重新载入，而不是重复刷写。若 FL2／FL3 没出现，保存当前现象并核对实际加载状态，不要直接再点安装。

## 8. 分开检查预览、照片，再点击「3 重開後核對」

先在相机上完成这些观察：

- 能正常进入取景画面，没有循环重启或错误。
- 对同一场景切换 ST、FL2、FL3，检查未按快门时的预览表现。
- 分别用 ST、FL2、FL3 拍一张**新照片**，并在相机回放。翻看旧照片不能验证新外观已正常拍摄。

然后设回大量存储模式、重新连接电脑，在工具选回**这次的工作目录**，点击 **「3 重開後核對」**。它检查程序、参数及相关运行片段；它不能替你判断屏幕上的实际色彩。

**完成标准：**工具明确显示“磁碟程式與保存參數符合預期”，且前面的菜单、预览、新照片和回放都正常。请分别记录工具检查和亲自观察的结果；磁盘核对成功不能单独证明整个相机稳定。

## 回到最初 backup2（开发版）

本节适用于 `feature/backup2-rollback`，旧 v2.1 下载不含这项功能。新版 prepare 在第二备份目录保存独立压缩档 `checkpoint.private.zip`：完整 AP／CP 程序、68 份名称资源、内存和已保存设置。后续导入 LUT 不会改写这个原始点。

接回大量存储模式后，用实际电量执行（`RollbackWork` 必须是新目录）：

```text
FL23.cmd rollback --backup-copy "E:/CameraBackup-A7C2-01" --workspace "D:/RollbackWork" --firmware-version 2.01 --battery-percent 90
```

它以 backup2 为目标，从当前状态生成回退，**不用先逐个撤销 LUT**。恢复程序、名称、FL23 参数／绑定和六个自订配方；写后逐字节完整读回。保留无关拍摄设置、计数器及工厂校准。backup2 是备份时的状态，只有当时未修改，回退才会回到未修改状态。

显示 `RESTORED_AWAITING_RELOAD` 后，完整断电重开，检查预览、新照片及回放，再执行：

```text
FL23.cmd rollback-verify --workspace "D:/RollbackWork" --accept-photos
```

新版 prepare 的原工作目录也可用桌面按钮「回到最初備份」，重启后按「3 重開後核對」。完整回退前会额外保存当前状态；日常 LUT 更新仍采用增量备份。

**旧 backup2** 缺少名称和单独的闪存设置快照，需原 FL23 工作目录与首次导入 LUT 前的 Job 补齐，见 [LUT 还原](custom-lut.md#8-必要时还原)。没保存的数据无法凭空恢复。本功能完成离线测试，尚未实机验证完整回退；仍需要可用的 USB 服务连接。

## 出问题时看这里

| 情况 | 应该做什么 |
|---|---|
| 双击工具打不开 | 检查完整解压、64 位 Python 3.10+、Tkinter 和联网条件；参考手动启动检查 |
| 没有识别到目标相机 | 核对机型、USB 大量存储、数据线和正确 USB 身份驱动 |
| 初始就绪／忙碌 | 工具有有界等待；若最终报错，保留日志，不反复点按钮 |
| 工作或备份目录不为空 | 新的准备使用新目录，原目录保留；安装／核对则继续使用准备成功的同一工作目录 |
| 超时、断线、`needs_review` 或写入结果未知 | 停止后续操作，保留整个工作目录，先查已有结果和文件状态，不盲目重写或重启 |
| 已写入但菜单没出现 | 先区分存储已更新和运行仍旧；不要用再次安装代替加载状态核对 |
| 相机循环重启 | 不继续反复尝试刷写；保留电源／连接现象和日志，需要针对实际状态制定恢复方案 |

排查时提供相机型号／版本、刚按的按钮、最后几行日志，以及是否还能进入菜单／取景。整个备份和机身原档不应公开。已有失败的具体教训见[历史错误](technical/failures.md)。
