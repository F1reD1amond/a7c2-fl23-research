preview.10.7：桌面、运行库及声音回归 334 项通过、20 项跳过，包含实际原厂程序兼容测试。独立离线脚本用已发布旧版补丁重建升级来源，先复现外部报告同位置 `0x138832` 冲突，迁移后通过；原厂／旧 FL23／旧 FL23＋LUT 三类均生成完整六款一键安装方案，重复 FL23 规划无额外修改，迁移保留非目标 LUT 程序字节。恢复 UI 已验证等待核对 70%、核对通过 100%、失败保留未完成状态、必须重启后核对弹窗，并实际渲染启动提示及恢复页面。本轮没有物理相机操作；外部包缺少实际源字节及原始子事务状态，仍需对方实测新版。

preview.10.6：156 项相关回归通过，覆盖没有试听／确认／恢复记录直接保存、保存当前转换而非旧试听、缺依赖时不创建写入意图、准备失败可新建及未知原生执行不重放。打包 EXE 使用机主程序备份和当前 3776 字节音频，实际执行三种 CSV 启动模拟（有效／缺失／超长）及逆向还原，完成五个原生 worker 的编译；无 USB。机主缺模块失败的任务已据空原生日志解除占用，原文件保留，恢复确认记录未撤销。本轮没有实际写入或验证开机音效。

preview.10.5：151 项相关回归通过。覆盖试听成功的保持开机弹窗、缺试听／确认／恢复时的保存引导、worker 退出后弹窗恰好一次、等待状态不误报安装完成、不代替用户确认，以及完成实际确认后可进入安装。已渲染检查两个 Qt 弹窗；打包 EXE 在机主当前已确认试听但未记录恢复的副本上返回 `sound_cold_recovery_required / camera_io=false`，无异常。原声音任务记录保留，本轮未操作相机或验证持久化写入。

preview.10.4：144 项相关回归通过，新增分配前 EEXIST 失败解锁、旧标记自动替换、完成报告／机身／令牌精确对应、活动 worker／未知结果不覆盖，以及旧证据保留。机主真实失败报告确认 `phase=1 / status=-17`，AP／CP／传输调用均为 0；已匹配历史完整注册报告。打包 EXE 在机主相机上成功保存并移除该旧标记，随后普通试听会新建标记；没有释放旧 CP 地址、注册新声音或写入固件。本轮实际声音仍待机主试听。

preview.10.3：相关离线用例 129 项通过。新增连接回归先原样复现旧机身记录缺少 USB 字段的错误，修正后覆盖旧／新记录、普通／服务身份、USB 返回等待、断连及认证失败不重试。通过打包 EXE 的 `sound_check_connection` 在机主相机上核对身份并读取 AP／CP，返回成功、磁盘声音开关为 OFF；没有调用 worker、注册声音、写程序或设置。此次没有实机播放验收。
