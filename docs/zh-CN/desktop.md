# A7C II 桌面工具（Windows 开发预览）

适用于 **ILCE-7CM2／固件 2.01**。启动软件不会连接相机；所有设备操作由你手动点击。macOS 构建暂缓。

## 连接

相机开机并选择海量存储模式。优先点 **准备两阶段驱动并测试连接**：先处理普通连接 `0E8A`，再处理服务设备 `0336`。已安装兼容类型的驱动会沿用；需要时才安装 WinUSB。

“单独安装所选身份的驱动”是高级入口，仅处理下拉框中的身份。**卸载相机驱动**会先导出驱动包，再卸载相机专用的第三方驱动，保留 Windows 自带驱动；完成后拔插 USB 让系统重新识别。驱动操作不修改相机固件。

`0336` 超时只能说明服务连接没有建立。准备连接能处理缺驱动的情况；相机没有完成切换、USB 不稳定等原因仍需看实际日志，不能一概保证修复。

## FL2／FL3

点 **启用／重新启用 FL2／FL3**，完成后完整断电重开并核对。已是目标状态时不会重复写入。

点 **从列表移除 FL2／FL3，保留自定义外观** 会关闭这两个列表入口。自定义外观、名称、共用色彩代码保留，所以之后可以重新启用。这不是清除所有项目修改。

## 自定义外观

选择 `.a7look`、栏位和名称，点 **写入所选栏位**。无需创建备份目录；转换已经在 A7Look 文件中完成，写入时不重新拟合。

**所选栏位恢复 ST 默认**不依赖原来的 LUT Job 或配方备份，不找回旧配方，保留其他栏位和 FL2／FL3。旧六槽布局会保留共用运行库，将所选槽的校正归零；新布局会关闭所选槽的导入标记。名称和照片效果仍需实机确认。

旁边的编译器接受 DCP／CUBE。DCP 需要 Lightroom 和显影桥接配置；直接 Sony ST／sRGB 输入的 CUBE 无需 Lightroom。LrC 自动识别插件用于后续 RAW 显影，不会把 DCP 烧进 RAW 像素。

## 无旧备份恢复原厂功能

点 **恢复原厂 2.01 功能（无需旧备份）**。工具内置本项目支持区域对应的原厂数据，无需整理旧备份，也无需下载完整固件。

恢复会移除已支持的 FL23、LUT／预览／名称、电子快门声音程序修改，并把六个自订栏位设为 ST 默认。机身校准、计数器和无关设置保留；旧自订配方不找回。只处理支持的程序区域和项目色彩字段，不是整块闪存镜像。未被原厂程序引用的项目音频文件／竖屏别名可能保留。

“使用旧备份回到过去的状态”作为折叠的可选入口保留。高级用户也能导入同型号同版本的原厂 `BODYDATA.DAT` 作为完整程序参考。相机仍必须能进入服务通信；这里不是索尼更新器的假降级，也不能保证修复无法连接的机身。

## 每次操作

写入前会弹窗提醒版本与供电条件；无需输入电量百分比。保持供电充足和 USB 连线，等待完整读回。工具不自动创建完整机身备份，保留事务日志、必要修改窗口和结果，未知写入不会自动重试。

看到“所有读写已结束”后，正常关机、拔掉 USB 和其他供电，等待存取灯熄灭，取出电池至少一分钟再开机。先检查即时预览、拍照／回放和名称，再接回点击核对。**离线对照、完整读回、加载验证与实际拍摄分别验收。**

错误日志实时显示；可用“导出诊断包”保留原始错误。诊断包含设备信息和本机路径，公开前请检查。

## 其他功能与开发状态

竖屏显示旋转的是拍摄信息／图标／布局，当前开关仅作用于运行会话；整个 MENU 不旋转。自定义快门声音仍采用先试听、确认和恢复试听状态，再保存的流程。

本轮完成了原厂区域重建、校准保留、FL23 移除／重启用、单槽 ST 默认、失败停止与界面的离线检查；新无备份流程**尚未实机验收**。仅开发分支，未更新 main 或正式 Release。

源码运行：安装 `desktop-requirements.txt` 后执行 `python desktop.py`。[给开发者／AI 的说明](../../dev/desktop/README.md)。
