# A7C II Windows 桌面工具

适用 **ILCE-7CM2／固件 2.01／64 位 Windows 10–11**。当前为开发测试版；启动软件不会连接或刷写相机。macOS 构建暂缓。

## 首页：一键安装

1. 相机选择“海量存储”，用资料线连接电脑并保持供电充足。
2. 默认勾选六款内置外观、FL2／FL3、原生电子快门声和竖屏显示。需要 Lightroom 自动识别时，再勾选插件。
3. **无需选文件。自订 1–6 依次替换为 NC（Classic Neg.）、CC（Classic Chrome）、NN（Nostalgic Neg.）、Astia、GR 正片、GR 负片**；原有创意外观保留。想改用自己的文件时，取消勾选内置六款，再展开自定义文件区；此模式下留空的槽位保持原样。
4. 点 **一键安装／继续上次安装**。工具准备两阶段驱动、合并所选程序／外观、写入并完整读回；需要管理员权限时，Windows 会提示。
5. 读写结束后会弹出步骤：**拔 USB 和其他外部供电 → 等存取灯停止闪烁 → 正常关机并等屏幕和灯完全熄灭 → 取下电池至少一分钟 → 装回开机**。也可点“如何断电重开”随时查看说明。
6. 重开并接回海量存储，再点**同一个按钮**。工具核对新开机与实际加载，包括已保存竖屏开关的运行状态，再接入声音工具及可选插件。不会为了继续流程重复刷写。

全部结束后会弹出“安装完成”，列出本次外观和功能；未选择的声音不会显示为已安装。首页“查看上次安装结果”不连接相机，也不会重新安装。先前已处理的报错保留在历史记录，不再显示为当前错误。

**新版竖屏与其他所选功能合并保存**：资源完整后才保存原生开关，随同一次安装的最终断电重开加载；不再要求每次连接电脑开启。旧任务保持原计划，可在竖屏页单独升级保存。新版持久化尚待机主实机验收。

若弹窗写的是“名称阶段完成，程序尚未写入”，说明旧资源仍被占用，需先恢复只读挂载。按弹窗完整断电、接回，再点同一个按钮继续程序安装；先不用拍照，也不需要重装驱动或重选文件。名称不会重复写入。程序完成后还会提示最终重开。若只读状态已自行恢复，工具会直接继续，不额外要求断电。

没有任何更改时，不会要求多余的断电重开。恢复出厂、卸载驱动和删除槽位不会混入安装流程。自定义声音仍需在声音页试听、确认后再保存。Lightroom 插件安装后需在其插件管理器中启用一次；它处理后续 RAW 显影，不会把 DCP 烧进 RAW 像素。

恢复原厂后再启用 FL23 属于新的程序修改，需要再次重开才能加载；加载核对只读取状态，不重复刷写。未完成的旧安装继续原计划，不会中途自动加入六款。内置外观是拟合近似，并非完整复现原 DCP；来源及版权保存在工具包 `desktop-assets/presets/default-six-v1/credits.json`。

## 连接与驱动

优先使用“准备两阶段驱动并测试连接”。普通海量存储与服务身份通常是 `054C:0E8A`／`054C:0336`；已有兼容驱动会沿用。卸载入口会导出相机驱动包，再恢复 Windows 默认连接。

检测会显示所有 Sony USB 身份、设备名称和接口信息。**编号不同不代表已经确认是同一机型**；`054C:0D68` 的具体来源目前未确认。工具会保留完整诊断，不会给未知 PID 自动替换驱动。先核对机身名称及 USB 模式。

## 单独开启、关闭与单槽操作

- **FL2／FL3：**可启用、重新启用或从列表移除。写入读回后按提示断电重开，在相机确认即可使用；电脑端加载核对收在可选诊断里，不是必做步骤。移除列表入口会保留自定义外观共用代码，之后可再启用。
- **自定义外观：**默认空清单。点“添加操作项”，选目标槽位及“恢复 ST 默认”或“写入 A7Look”；新增项默认恢复。写入时文件和机内名称放在同一项，名称留空沿用文件内名称。可混合多个槽位的写入与恢复，未添加的槽位保持原样；恢复不找回旧配方。导入槽使用 ST，基础外观选择器仍可编辑。
- **竖屏显示：**只转向拍摄信息／图标／布局，整个 MENU 不旋转。新版保存原生开关，随最终断电重开加载；关闭会先保存 OFF，再关闭运行开关、清理辅助资源。无需每次重新连接电脑开启。持久化尚待实机验收。
- **声音：**支持原生开关及音频转换，转换后直接保存；临时试听和确认记录可选。已由一键安装启用的声音可接入该工具，不重复刷写；听不到时先检查机内音频信号设置。

重复导入同名外观不会不断追加名称。名称先完成事务，再让程序引用；新名称按文件逐个原子替换，避免同时暂存 68 份完整文件。完整读回后才提示重开。

一键安装会显示普通／服务 USB 身份的驱动检测结果。已有 WinUSB／libusbK／libusb0 时沿用，不重复安装或申请管理员权限。仅缺少兼容绑定时才安装。

旧版一键安装若记录为名称阶段 `ENOSPC / -28`，点“继续”会先核对报告、当前程序窗口及原名称绑定。只有确认名称与程序均未提交、回滚／清理／只读挂载成功，才清理该次精确匹配的临时 worker／报告，并创建新事务重试；原失败目录保留。部分提交、结果未知或字节不符时继续停止，不自动重刷。

若名称已全部提交、仅只读挂载返回 `EBUSY / -16`，新版会核对全部名称和原程序、准备重新加载，并提示上述资源阶段重开。报告缺失、提交不全、回滚／清理失败或当前内容不同，不会按此路径放行。

当前桌面版同步了 [FL23 PR #6](https://github.com/QAQLeonard/a7c2-fl23-research/pull/6) 的照片／视频分流修正：FL2／FL3 视频改用对应视频曲线，保留自定义 LUT；不把视频曲线修正当作照片色差已校准。

## 恢复原厂功能

已经加载并核对完成的历史恢复不会阻止再次恢复。后续安装过功能时，再点主恢复按钮会按当前状态新建恢复计划；只有确实未完成的事务才自动续接。

点 **恢复／继续恢复原厂 2.01 功能**，无需旧备份或下载整份固件。移除已支持的项目修改，六个自订栏位设为 ST 默认，保留机身校准、计数器和无关设置。旧备份完整回退仍是可选入口；这不是索尼更新器的降级，也不是整块闪存覆盖。

中断后仍点同一个按钮。工具读取已有结果和当前字节，只处理未完成部分；无法确认执行结果时会停止并保留现场。名称恢复的临时空间不足和只读挂载忙碌分别处理：只有内容已完整核对、无需再改程序／名称时，才可完成剩余设置并等待正常断电重开；之后必须核对新开机和只读挂载，才完成加载验证。

## 报错与验证范围

完整错误在窗口及任务日志中保留，可导出诊断包。公开日志前检查设备信息和本机路径。不要用重复刷写来解决尚未确认的结果。

离线回归覆盖各槽写入／重写／撤销、混合槽位保留、两种安装顺序、驱动、恢复、声音、竖屏与一键流程。本机已完成这次原厂恢复的完整读回、新开机／加载及只读挂载核对；**新一键流程和所有功能尚未逐项实机拍摄验收**。颜色拟合、照片输出、实时预览与长期稳定性分别验证。

源码运行：安装 `desktop-requirements.txt`，执行 `python desktop.py`。[测试结果与边界](desktop-validation.md) · [开发者说明](../../dev/desktop/README.md)。本轮只更新开发分支与本机测试包，未更新 main／正式 Release。

自定义页点“查看并应用”会列出完整清单，再确认供电。写入／完整读回后按弹窗断电重开，同一按钮变为加载核对；等待期间清单锁定，核对完成后清空。明确在写入前失败时可以调整重试；结果未知时保留任务记录并停止。首页的一键安装仍可默认装入六款，与此页的空清单分开。

音频转换是独立的电脑端操作：每次新建任务，无需先启用相机声音，不受旧相机任务锁定。失败或取消会清理本次临时输出，源文件和上一份成功结果保留。当前候选保存在单独的转换记录中；转换成功不代表已试听或写入相机。

首次相机试听前先开启电子快门声并按提示断电重开。已启用的声音可通过只读检查直接接入。旧开启任务如果已证明未进入写入、检查与清理均完整，下次点击会自动解除占用并保留旧日志；无法确认结果的任务仍停止。若提示“电子快门声尚未开启”，先点“开启电子快门声”，不要反复点试听。临时试听不负责写入永久开关。

声音使用原有的 Sony 服务机身身份，旧声音任务不需要补填 LUT 的 USB 描述符字段。声音 CLI 的 `check-connection --workspace <声音工作目录>` 可只读取机身和当前声音程序，不注册试听、不写程序或设置；`status` 仍只读本机记录、不连接相机。

试听前会自动保存并替换已完成试听留下的占用标记，正常操作不需要手动删文件。上次若仅因旧标记在分配前停止，新一次点击会自动开始新任务。旧 CP 缓冲不会按过期地址释放，断电时统一回收；未知执行或标记无法对应完整报告时会保留证据并说明原因。

转换成功后直接点“保存当前自定义声音”，无需先试听、确认或断电恢复。试听是可选步骤，成功后会弹窗提示拔 USB、保持开机试拍；接回后也可直接保存。试听确认与恢复记录收在可选区域，不影响保存。只有实际写入和读回完成后，才按弹窗拔 USB、等灯停、关机、取电池至少一分钟，重新开机加载。
