# Reproduce the A7Look pipeline

[简体中文](../zh-CN/a7look-ai.md) · [User overview](a7look-suite.md)

Read root `AGENTS.md` and `src/looks/AGENTS.md`. Stay on the feature branch; no camera execution or publication is implied by an offline task.

1. **Generate:** `a7look_compile.py` / `looktool.compilelook` takes A7C II DCP or explicitly described CUBE input. DCP references use numerical Bayer DNGs and actual Adobe rendering; CUBE references use the declared ST domain/bridge directly. `measuredmodel` predicts the calibrated camera response; `nativefit` fits and quantizes native stages plus all 1,215 correction bytes. Report held-out prediction separately from camera error. More compute is optional, not evidence of accuracy outside measured conditions.
2. **Write:** `a7look_write.py` dispatches the existing CLI to `devicejob.Job`. Freeze the file without refitting. `photoio` reconstructs and byte-compares existing native code, preserves other slot parameters, and checks project allocation/loaded extents. On stock first construct the existing reviewed six-table runtime before extracting its relocated ST gamma rows. Read ST matrix/chroma from the destination body's fresh CP units; never copy another body's calibration.
3. **Restore:** keep two reconstructable compressed stores and an exact inverse. Single-slot restoration compares the selected table, native parameters, title, and recipe against the accepted Job while allowing later other-slot/FL23 changes. Restore old native parameters and known source-DCP attribution too. Do not add old firmware hash gates. Complete initial rollback belongs to `recovery.py`.
4. **Adobe:** `.a7look` carries an immutable source DCP. Only accepted writer outcomes publish dated history. `raw_auto.py` installs the standalone Lightroom watcher; normal imports route markers 249–254 by capture time. Keep native looks/existing edits untouched. Verify real exported profile metadata: the getter can echo unavailable names. Preserve the imported profile on fallback and queue the pending new import for restart. Camera clock/history remain necessary; RAW has no source-version ID. CUBE does not automatically become an Adobe profile.
5. **Verify:** use `test_photoio`, `test_lookfile`, `test_compile_cube`, `test_rawidentity`, `test_rawauto_lua`, and `test_native_device_job`. The last requires `A7C2_RESEARCH_FIXTURES` plus `A7C2_NATIVE_CHECKPOINT` and uses simulated transport. Put `src/looks` on `PYTHONPATH` so child-process lock tests can import it. Optional fixture skips are not passes. Compile real native workers and check full byte inverses before any authorized physical trial.

The new plugin passed integrated Lightroom rendering and restart-queue acceptance. The packaged general writer passed slot-4 Astia installation, full readback, fresh-boot/AP loaded checks and owner preview/photo/playback acceptance on one Windows body. Final six-look camera color accuracy and physical single-slot restoration remain separate pending checks. Do not infer safe camera boot from emulation/readback, or invoke install to repair a stale preview. Unknown write outcomes stop and preserve evidence. Keep full firmware/body backups/photos/private manifests outside public artifacts. Camera Raw is optional and currently has no independent automatic plugin.
